# 01. 요구사항 정의서

## 1. 목표

한 페이지 안에서 "내가 누구이고, 무엇을 할 수 있고, 어떻게 연락하는지"를 30초 안에 전달한다.

## 2. 대상 사용자

| 대상 | 관심사 | 페이지에서 원하는 것 |
|---|---|---|
| 채용 담당자 / 면접관 | 기술 스택, 경력, 결과물 | 스킬 목록, 프로젝트, 이력서 다운로드 |
| 협업 제안자 | 전문 분야, 연락 방법 | 소개, 연락처, SNS 링크 |
| 지인 / 방문자 | 근황, 관심사 | 자기소개, 블로그 링크 |

## 3. 기능 요구사항

### 필수 (MVP)

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 히어로 영역 | 프로필 사진, 이름, 한 줄 소개, CTA 버튼 2개 |
| F-02 | 소개(About) | 2~4문장 자기소개, 관심 분야 |
| F-03 | 스킬 목록 | 카테고리별 기술 스택 태그 |
| F-04 | 프로젝트 카드 | 썸네일, 제목, 설명, 사용 기술, 링크(데모/코드) |
| F-05 | 연락처 | 이메일, GitHub, 그 외 SNS 아이콘 링크 |
| F-06 | 네비게이션 | 상단 고정 메뉴, 클릭 시 해당 섹션으로 부드럽게 스크롤 |
| F-07 | 반응형 | 모바일·태블릿·데스크톱 대응 |

### 선택 (여유 있으면)

| ID | 기능 | 설명 |
|---|---|---|
| F-08 | 다크 모드 토글 | 버튼으로 전환, `localStorage`에 선택 저장 |
| F-09 | 스크롤 등장 애니메이션 | `IntersectionObserver`로 섹션 페이드인 |
| F-10 | 프로젝트 필터 | 기술 태그별로 프로젝트 카드 필터링 |
| F-11 | 경력/학력 타임라인 | 연도순 세로 타임라인 |
| F-12 | 맨 위로 버튼 | 일정 스크롤 이후 우하단에 노출 |
| F-13 | 타이핑 효과 | 히어로의 한 줄 소개에 타자 애니메이션 |

## 4. 비기능 요구사항

- **성능**: 이미지 최적화(WebP 권장, 프로필 사진 200KB 이하), 첫 화면 로딩 2초 이내
- **접근성**: 모든 이미지에 `alt`, 아이콘 링크에 `aria-label`, 키보드 Tab 이동 가능, 본문 대비비 4.5:1 이상
- **브라우저**: Chrome / Edge / Safari / Firefox 최신 2개 버전
- **SEO**: `<title>`, `meta description`, Open Graph 태그(카카오톡·트위터 공유 시 미리보기)
- **의존성**: 외부 프레임워크 없음. 아이콘·폰트만 CDN 허용

## 5. 범위 밖 (하지 않는 것)

- 로그인 / 회원가입
- 서버, 데이터베이스, 백엔드 API
- 방명록·댓글 등 서버가 필요한 기능 (필요 시 외부 서비스 임베드로 대체)
- 다국어 전환 (한글 단일 언어)
