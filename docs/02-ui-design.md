# 02. 화면 설계서

> ℹ️ **이 문서의 About / Skills / Projects / Contact 부분은 `about.html`(소개 페이지)에 그대로 쓰입니다.**
> 다만 Hero가 화면 전체를 채우던 1페이지 구성은 더 이상 쓰지 않습니다.
> 블로그 쪽 화면(목록·상세·작성·로그인·회원가입·프로필)은 이 문서에 없습니다.

## 1. 페이지 구조

**다중 페이지(MPA) 구조.** 메뉴 항목마다 별도 HTML 파일을 가진다.

```
Header (모든 페이지 공통 · 상단 고정)
  └ 메뉴(Home · About · Skills · Projects · Contact) · 다크모드 토글
       ※ 왼쪽 로고(이름) 없음. Home 항목이 그 역할을 대신한다.

index.html     Hero        — 사진 + 이름 + 한 줄 소개 + [프로젝트 보기]
about.html     About       — 자기소개 + 정보 배지
skills.html    Skills      — 카테고리별 기술 태그
projects.html  Projects    — 프로젝트 카드 그리드
contact.html   Contact     — 메일 버튼 + SNS 링크

Footer (모든 페이지 공통)
```

헤더·푸터 마크업은 5개 파일에 그대로 복제되어 있다(빌드 도구 없음).
**메뉴를 고치면 5개 파일 모두 수정해야 한다.**

## 2. 와이어프레임 (데스크톱 1280px)

### Header — 상단 고정, 높이 64px

```
┌──────────────────────────────────────────────────────────┐
│  홍길동            About  Skills  Projects  Contact   🌙  │
└──────────────────────────────────────────────────────────┘
```
- `position: sticky; top: 0;`
- 스크롤 시 배경 반투명 + 하단 그림자 (JS로 `.scrolled` 클래스 토글)

### Hero — 화면 높이의 80~90%

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│   ┌────────┐    안녕하세요,                              │
│   │        │    프론트엔드 개발자 홍길동입니다            │
│   │ 프로필 │                                             │
│   │  사진  │    사용자 경험을 고민하는 주니어 개발자      │
│   └────────┘                                             │
│                [ 프로젝트 보기 ]  [ 연락하기 ]           │
│                                                          │
│                        ↓ scroll                          │
└──────────────────────────────────────────────────────────┘
```
- 좌: 원형 프로필 이미지 (200×200)
- 우: 인사말(작게) → 이름+직군(가장 크게) → 한 줄 소개 → CTA 버튼 2개
- 주 버튼은 채움(primary), 보조 버튼은 테두리(outline)

### Skills — 카테고리별 태그 그리드

```
┌──────────────────────────────────────────────────────────┐
│  Skills                                                  │
│  ──────                                                  │
│  Frontend   [HTML] [CSS] [JavaScript] [React]            │
│  Backend    [Node.js] [Express]                          │
│  Tools      [Git] [Figma] [VS Code]                      │
└──────────────────────────────────────────────────────────┘
```
- 태그는 pill 형태(둥근 모서리 + 옅은 배경)
- 숙련도 막대는 주관적이라 권장하지 않음. 넣는다면 3단계(상/중/하) 정도로만

### Projects — 카드 그리드

```
┌──────────────────────────────────────────────────────────┐
│  Projects                                                │
│  ────────                                                │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐          │
│  │  썸네일    │  │  썸네일    │  │  썸네일    │          │
│  ├────────────┤  ├────────────┤  ├────────────┤          │
│  │ 프로젝트명 │  │ 프로젝트명 │  │ 프로젝트명 │          │
│  │ 한 줄 설명 │  │ 한 줄 설명 │  │ 한 줄 설명 │          │
│  │ #JS #CSS   │  │ #React     │  │ #Node      │          │
│  │ Demo  Code │  │ Demo  Code │  │ Demo  Code │          │
│  └────────────┘  └────────────┘  └────────────┘          │
└──────────────────────────────────────────────────────────┘
```
- `grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))`
- 카드 hover: `translateY(-4px)` + 그림자 강화 (transition 0.2s)
- 썸네일 비율 16:9 고정 (`aspect-ratio: 16/9; object-fit: cover`)

## 3. 반응형 규칙

| 구간 | 폭 | 레이아웃 |
|---|---|---|
| 모바일 | ~ 767px | 1단. Hero 세로 정렬(사진 위, 텍스트 아래). 메뉴는 햄버거 버튼 → 클릭 시 전체화면 오버레이 |
| 태블릿 | 768 ~ 1023px | 프로젝트 2열. 헤더 메뉴 노출 |
| 데스크톱 | 1024px ~ | 프로젝트 3열. 콘텐츠 최대 폭 1120px, 좌우 중앙 정렬 |

- 기준: **모바일 퍼스트**. 기본 CSS는 모바일, `@media (min-width: …)`로 확장
- 좌우 여백: 모바일 20px, 데스크톱 24px

## 4. 인터랙션 명세

| 동작 | 트리거 | 결과 |
|---|---|---|
| 메뉴 클릭 | 클릭 | 해당 페이지로 이동 |
| 현재 페이지 표시 | 페이지 로드 | 주소의 파일명과 일치하는 메뉴에 `.active` + `aria-current="page"` |
| 헤더 축소 | 스크롤 > 50px | 헤더에 `.scrolled` 클래스 (배경/그림자 변경) |
| 햄버거 메뉴 | 클릭 | 모바일 메뉴 열기/닫기, `aria-expanded` 갱신 |
| 다크 모드 | 토글 클릭 | `<html data-theme="dark">` 전환 + localStorage 저장 |
| 섹션 등장 | 뷰포트 진입 | `.visible` 추가 → opacity 0→1, translateY 20px→0 |
| 카드 hover | 마우스 오버 | 살짝 떠오름 + 그림자 |

> 접근성: 애니메이션은 `@media (prefers-reduced-motion: reduce)`에서 모두 끈다.
